# FastAPI File Upload Basics
FastAPI provides:

from fastapi import UploadFile, File

Example:
from fastapi import FastAPI, UploadFile, File
app = FastAPI()
@app.post("/upload")
async def upload_file(file: UploadFile = File(...)):
    return {
        "filename": file.filename,
        "content_type": file.content_type
    }

Upload using Swagger UI:
POST /upload
Choose a file and submit.

Response:
{
  "filename": "photo.jpg",
  "content_type": "image/jpeg"
}

# UploadFile vs Bytes
UploadFile
file: UploadFile

Advantages:

Uses temporary file storage
Memory efficient
Suitable for large files

Example:

contents = await file.read()
Bytes
file: bytes = File(...)

Entire file loads into RAM.

Good for:

Small files

Bad for:

Large files
Validate File Type

Suppose only images are allowed.

ALLOWED_TYPES = [
    "image/jpeg",
    "image/png"
]

Validation:

if file.content_type not in ALLOWED_TYPES:
    raise HTTPException(
        status_code=400,
        detail="Invalid file type"
    )
Validate File Size

Maximum 5 MB

MAX_SIZE = 5 * 1024 * 1024

Check size:

contents = await file.read()

if len(contents) > MAX_SIZE:
    raise HTTPException(
        status_code=400,
        detail="File too large"
    )

Reset pointer:

await file.seek(0)
Save File to Disk

Project Structure

app/
uploads/

Create folder:

import os

os.makedirs("uploads", exist_ok=True)

Save:

file_path = f"uploads/{file.filename}"

with open(file_path, "wb") as buffer:
    buffer.write(await file.read())

Response:
{
  "message": "File uploaded"
}

Generate Unique File Names
Avoid:
image.jpg
image.jpg
image.jpg

Use UUID:
import uuid
unique_name = f"{uuid.uuid4()}.jpg"

Example:
filename = f"{uuid.uuid4()}_{file.filename}"

Output:
8e3b7f_product.jpg

# Serve Static Files
After uploading images:
uploads/
   photo.jpg
Need browser access.

StaticFiles
from fastapi.staticfiles import StaticFiles

# Mount:
app.mount(
    "/uploads",
    StaticFiles(directory="uploads"),
    name="uploads"
)

Now:
http://localhost:8000/uploads/photo.jpg
returns image.

# Image Resizing using Pillow

Original:
5000 x 4000
Too large.

Resize:
800 x 600

Benefits:
-> Faster loading
-> Less storage
-> Better performance

Install Pillow
pip install pillow

Open Image
from PIL import Image
image = Image.open(path)

Resize
image = image.resize((800, 600))

Save:
image.save(path)

Thumbnail
Maintains aspect ratio.
image.thumbnail((800, 800))

Example:
img = Image.open(path)
img.thumbnail((800, 800))
img.save(path)


## WEBSOCKET
Normal HTTP:
Client → Request
Server → Response
Connection Closed

WebSocket:
Client ↔ Server
Connection Remains Open
Bidirectional communication.

# HTTP vs WebSocket
HTTP	                    WebSocket
Request Response	        Full Duplex
Stateless	                Persistent
New Connection	            Same Connection
Slower Real-Time	        Fast Real-Time

WebSocket Protocol
HTTP:
http://
https://

WebSocket:
ws://
wss://

Secure:
wss://


Browser Tab 1
ws.send("Hello Tab 2")

Hello Tab 2
