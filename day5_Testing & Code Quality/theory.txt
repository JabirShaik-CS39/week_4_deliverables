## Testing & Code Quality in FastAPI — Complete Detailed Guide

Testing and code quality are critical in production applications. They help ensure:

APIs work as expected
New features don't break existing functionality
Bugs are caught early
Code remains maintainable
Team collaboration becomes easier
CI/CD pipelines can automatically verify code
1. pytest + pytest-asyncio for FastAPI
What is pytest?

pytest is Python's most popular testing framework.

Features:

Simple syntax
Powerful assertions
Fixtures support
Parameterized tests
Async testing support
Coverage integration

Install:

pip install pytest
Why pytest-asyncio?

FastAPI heavily uses async functions.
Example:

@app.get("/")
async def get_users():
    return {"users": []}
Normal pytest cannot directly run async functions.

Install:
pip install pytest-asyncio

Example Async Test
Function:

async def add(a, b):
    return a + b

Test:

import pytest

@pytest.mark.asyncio
async def test_add():
    result = await add(2, 3)

    assert result == 5

Execution:

pytest
Project Structure
app/
├── api/
├── models/
├── services/
├── main.py

tests/
├── test_users.py
├── test_auth.py
├── conftest.py

## Test Database Setup
Never test against production DB.
Create separate testing database.

Option 1: SQLite In-Memory
Fast and simple.
DATABASE_URL = "sqlite+aiosqlite:///:memory:"

Advantages:
-> Extremely fast
-> No setup
-> Temporary

Disadvantage:
-> Slightly different from PostgreSQL

Example
engine = create_async_engine(
    DATABASE_URL
)

Create tables:

async with engine.begin() as conn:
    await conn.run_sync(
        Base.metadata.create_all
    )
Option 2: Test PostgreSQL

Better for production parity.

Production:
PostgreSQL

Testing:
PostgreSQL Test DB

Example:
postgresql+asyncpg://
test_user:test_pass
@localhost/test_db
Dependency Override

Production:

def get_db():
    ...


Testing:
app.dependency_overrides[
    get_db
] = override_get_db
FastAPI automatically uses test database.

7. Testing Edge Cases and Error Responses
Most bugs occur in edge cases.

Missing Field
response = await client.post(
    "/users",
    json={}
)
assert response.status_code == 422

Invalid Email
response = await client.post(
    "/users",
    json={
        "email":"abc"
    }
)
assert response.status_code == 422

Duplicate User
response = await client.post(
    "/users",
    json=user
)
assert response.status_code == 409

Resource Not Found
response = await client.get(
    "/users/999"
)
assert response.status_code == 404

Unauthorized
response = await client.get(
    "/profile"
)
assert response.status_code == 401

Edge Case Checklist
-> Empty strings
-> Null values
-> Duplicate records
-> Negative numbers
-> Invalid IDs
-> Unauthorized access
-> Large payloads
-> Expired JWT
-> Database failures

8. Mocking External Services (unittest.mock)
External services should not be called during testing.

Examples:
-> Email Service
-> Payment Gateway
-> AWS S3
-> OpenAI API
-> SMS API


## Mock It
from unittest.mock import patch
@patch(
 "app.services.email.send_email"
)


def test_register(mock_send):

    mock_send.return_value = True

    ...

Verify Called
mock_send.assert_called_once()

Mock OpenAI
@patch(
 "app.services.ai.generate_text"
)

def test_ai(mock_ai):

    mock_ai.return_value = "hello"

    ...

No API costs.
No internet dependency.

Tests run fast.

MagicMock Example
from unittest.mock import MagicMock

mock_db = MagicMock()

mock_db.commit.return_value = None

10. Pre-Commit Hooks

Automatically run checks before commit.

Install:

pip install pre-commit
Tools
Black

Code formatter.

pip install black

Format:

black .
isort

Sort imports.

pip install isort

Example:

Before:

import os
from fastapi import FastAPI
import sys

After:

import os
import sys

from fastapi import FastAPI
flake8

Linting.

pip install flake8

Finds:

Unused imports
Long lines
Style issues
mypy

Static type checking.

pip install mypy

Example:

def add(a: int, b: int) -> int:
    return a + b

Error:

add("a", 10)

Mypy catches this.

## .pre-commit-config.yaml
repos:
  - repo: https://github.com/psf/black
    rev: 24.4.2
    hooks:
      - id: black

  - repo: https://github.com/PyCQA/isort
    rev: 5.13.2
    hooks:
      - id: isort

  - repo: https://github.com/PyCQA/flake8
    rev: 7.1.0
    hooks:
      - id: flake8

  - repo: https://github.com/pre-commit/mirrors-mypy
    rev: v1.10.0
    hooks:
      - id: mypy

Install:

pre-commit install

Now every commit runs checks automatically.
